# RAG System Test Matrix

日期：2026-05-27

## 覆盖目标

本轮测试按“功能模块 x 场景类型”设计，场景类型统一覆盖：

- 正常流程：用户按预期操作时系统返回正确结果
- 参数边界：空值、缺参、默认值、上限下限、可选字段
- 权限身份：管理员、普通访客、H5 门店入口、会话归属
- 异常回退：依赖失败、数据不存在、外部服务异常、解析失败

## 功能矩阵

### 1. 系统与认证

- 根路由：系统元信息、默认模型、支持模型列表
- 模型列表：模型名称、提供方、最大 token、默认模型
- 健康检查：API key 配置态、默认模型、SSL 配置
- 登录：正确凭据、错误凭据、token 内容、过期时间
- 当前用户：管理员身份回显
- 退出登录：成功响应

### 2. 会话与身份

- 访客会话列表：按知识库过滤、不按知识库过滤
- 新建会话：标题、知识库、请求用户绑定
- 获取消息：默认条数、指定条数、跨用户访问
- 删除会话：本人删除、越权删除
- H5 身份：`user_id`、`nickname`、`sender_id` 注入
- Header 身份：`X-Guest-Id`、`X-Sender-Id`、`X-Requester-Name`

### 3. 知识库问答

- 普通问答：命中知识库后正常回答
- 流式问答：SSE done 事件结构、会话 ID 回传
- 多轮问答：历史上下文续接
- 澄清工单流：操作型问题、歧义问题、缺知识问题
- 工单追问回复：命中活跃工单时续接澄清链路
- AI 自动解决工单：高质量回答时写入工单记录
- 来源生成：source 去重、排序、字段完整性

### 4. 文档导入与切分

- 单文件上传：TXT/PDF/DOCX/Excel 上传任务提交
- 上传到分类：仅入 OSS，不触发切分
- 批量上传：部分成功、部分失败、总数统计
- Excel 列探测：sheet 列名返回
- Excel 专用切分：默认行数、自定义列配置、非法 JSON
- 分类切分：默认参数、自定义 chunk 参数、图谱同步开关
- 文档搜索：`kb_name` 与 `collection` 二选一、混合检索、rerank 开关
- 图片代理：PNG/JPG/WEBP 媒体类型正确

### 5. 分类、文件、任务、切片

- 分类 CRUD：创建、查询、更新、删除
- 分类文件删除：单删、批删
- 文件列表：分页上限、知识库过滤
- 文件删除：单删、批删
- 文件直出：MIME 推断、记录不存在、内容为空、读取异常
- 任务列表：知识库过滤、条数限制
- 任务详情：正常返回
- 任务重新向量化：异步成功返回
- 切片查看：按任务取切片
- 单切片编辑/清洗/回滚
- 批量清洗/批量回滚
- 全量清洗/全量回滚
- 单任务上传向量库、批量上传向量库
- 切片图片管理：列出、添加、删除
- 图片占位符解析、OSS key 批量签名解析

### 6. 知识库与图谱管理

- 公共知识库列表：仅暴露前台需要字段
- 管理端知识库列表：数量统计
- 创建知识库：标准库、多模态库、重复名冲突
- 更新知识库：检索配置合并更新
- 删除知识库：空库删除、存在文件阻止删除、Milvus 删除失败时继续清理 PG
- 图谱查询：知识库不存在、无同步文件、有同步文件、有文件查询异常
- 配置查询：Milvus 集合读取成功与失败兜底

### 7. 前端入口与导航

- 普通入口：聊天页、历史页、管理员入口
- H5 门店入口：隐藏后台入口、展示身份 pill、固定聊天视图
- 后台导航：设置页高亮仅作用于设置相关菜单
- 配置展示：新配置结构与旧配置结构兼容
- 构建产物：`vite build` 成功

## 本轮执行方式

- 后端单元与服务测试：`backend` 下 `pytest`
- 后端覆盖率回扫：`pytest --cov=app --cov-report=term-missing`
- 前端轻量测试：`node --test tests\\*.test.mjs`
- 前端构建验证：`npm run build`
- 路由补充测试：新增 API 契约测试，确保未覆盖入口被真实执行
- 运行态冒烟：启动依赖服务后对 HTTP 入口做健康和关键接口验证

## 判定标准

- 通过：返回结构、状态码、委托参数与预期一致
- 失败：断言不符、抛异常、响应结构缺字段
- 阻塞：需要外部密钥、外部模型服务、现网数据或人工视觉确认
